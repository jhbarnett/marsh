# config/

Your instance bindings. Real configs are **untracked** (see `.gitignore`);
`*.example.json` templates are tracked.

| File | Source | What |
|---|---|---|
| `taxonomy.json` | generated by `/marsh:sync`, human-confirmed | your workspace's teams, status-name → status-type maps, label-group semantics, intake paths, cycle conventions |
| `registry.json` | copy from `registry.example.json` | target repos: path, base branch, verify commands (`gate` = the canonical agent Stop-gate command), domains, teams, risk class |
| `policy.json` | copy from `policy.example.json` | lanes + WIP limits, risk-scaled gates by shape/risk class, escalation ladder, budgets, witness thresholds |
| `roles/` | ships with the plugin, tune freely | per-hat checklists and definitions of done |
